# Product

**To-Do List Life Dashboard** — a simple, browser-based personal dashboard built by Amalia as part of the CodingCamp (cohort starting September 26).

## Purpose

A single-page dashboard that helps users organize their day. It combines a live clock/greeting, a Pomodoro focus timer, a to-do list, and quick-access website links — all without any backend or login.

## Required Features (MVP)

### Greeting
- Display current time and date
- Show a time-based greeting (e.g., Good Morning / Afternoon / Evening)

### Focus Timer
- 25-minute Pomodoro timer
- Start, stop, and reset controls

### To-Do List
- Add, edit, mark as done, and delete tasks
- Persist tasks using Local Storage

### Quick Links
- Buttons that open favorite websites
- Links saved and loaded from Local Storage

## Optional Features (choose 3 of 5)
- Light / Dark mode toggle
- Custom name in greeting
- Configurable Pomodoro duration
- Prevent duplicate tasks
- Sort tasks
