# Tech Stack

## Stack

- **HTML** — page structure
- **CSS** — styling (1 file only: `css/style.css`)
- **Vanilla JavaScript** — all logic (1 file only: `js/app.js`). No frameworks (no React, Vue, etc.)
- **Local Storage API** — all data persistence, client-side only
- **No backend, no build tool, no test framework required**

## Browser Compatibility

Must work in modern versions of Chrome, Firefox, Edge, and Safari. Can run as a standalone web page or browser extension (homepage-style).

## Running the Project

No build step needed. Open `index.html` directly in a browser:

```
# Option 1 — open the file directly
Double-click index.html

# Option 2 — use a local dev server (optional, e.g. VS Code Live Server)
Right-click index.html → Open with Live Server
```

## Performance Requirements

- Fast load time (no heavy dependencies)
- Responsive UI with no noticeable lag on data updates
